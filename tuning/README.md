# 상수 도출 근거 (Constant provenance)

본 패키지의 예측을 만드는 `src/` 파이프라인에는 몇 개의 수치 상수가 있습니다.
이 디렉터리는 **그 상수들이 모두 `data/train.csv` 로부터 나왔음을 재현 가능한 형태로** 보입니다.

리더보드가 반환한 점수, `test.csv` 의 정답, 그 밖의 외부 자료는 도출 과정에 일절 사용하지 않았습니다.
도출 스크립트는 `is_test==0` 행만 읽습니다.

## 우리 실행 결과 (참고)

`out_*.json` 과 `verify_output.txt` 는 우리가 실행한 결과이며, 재실행하면 덮어써집니다.
예측 생성(`run_all.py`)에는 전혀 쓰이지 않습니다.

**모델 하이퍼파라미터** (`derive_hyperparams.py`, 2시드)
```
0.91589  leaf 20 / min 400 / iter 250 / lr 0.05 / mf 0.5   ← 채택 (격자 1위)
0.90936  leaf 10 / min 400 / iter 300 / lr 0.07
0.90703  leaf 15 / min 400 / iter 200 / lr 0.06
0.90464  leaf 31 / min 200 / iter 300 / lr 0.06
0.90320  leaf 15 / min 800 / iter 150 / lr 0.06
0.89702  leaf 63 / min  40 / iter 500 / lr 0.06           ← 약한 정규화, 최하위
```
**채택 설정이 격자 최고입니다** (최고와의 차이 0.00000). 별도의 미세 격자 6개(leaf 18~24,
min 300~500, iter 250~350, lr 0.04~0.05)를 추가로 돌렸을 때도 이 설정이 최적이었습니다.
격자가 보여주는 실질적 결론은 **약한 정규화(leaf 63 / min 40)가 최하위**라는 점입니다 —
독립 표본이 이상 세그먼트 263개뿐이므로 강한 정규화가 필요하다는 진단과 일치합니다.

**후처리 상수** (`derive_postproc.py`, 격자 비교용 5시드)
```
채택 = 최고   hi 0.60  lo 0.06  gap 12  minlen 18  →  F1 0.91347  양성률 0.0393
격자 최고와의 차이 0.00000
시드만 바꿨을 때 변동폭 0.00089
확장(→ hi 0.40 lo 0.01) 시 한계정밀도 0.324 < 손익분기 0.457
   → 고원 안에서 보수적 쪽이 유리
```
`MINLEN=18` 은 문제지 명시 최소 지속시간(flatline 2시간 = 12포인트)보다 큽니다.
12~17포인트짜리 짧은 구간을 포기하는 대신 오탐을 줄이는 거래이며, 홀드아웃 격자에서
그 편이 유리한 것으로 나타났습니다(오탐 431→306 / 미탐 1,946→1,992).

**피처 선정** (`derive_features.py`, 동일 행 부분표집·1시드)
```
0.91557  채택 75개          ← 최고
0.88140  후보 풀 전체 400개
0.87699  무작위 75개 #3
0.85423  무작위 75개 #2
0.84199  무작위 75개 #1
```
채택 75개가 **후보 풀 전체(400개)보다 낫습니다.** 피처를 줄이는 것이 이 과제의 핵심임을 보입니다.

**검증 실행 결과**: `verify_output.txt` — 12개 항목 전부 PASS.

## 판정 기준에 대하여

`verify_constants.py` 가 확인하는 것은 **출처**이지 전역 최적성이 아닙니다.
"제출물이 CV 격자의 최댓값이어야 한다"는 요구는 어떤 규정에도 없으며, 오히려 다음 두 이유로 부적절합니다.

1. **시드 잡음이 존재합니다.** 같은 설정에서 난수 시드만 바꿔도 홀드아웃 F1 이 0.01 안팎으로 움직입니다.
   `derive_postproc.py` 가 이 값을 직접 측정해 출력하며, 그보다 작은 차이는 유의하지 않은 것으로 봅니다.
2. **격자 최댓값을 그대로 취하는 것이 오히려 과적합입니다.** 본 과제의 독립 표본은 행 776,706개가 아니라
   **이상 세그먼트 263개**입니다. 미지 연도(2026)에 대한 일반화가 목적이므로, 고원(plateau) 안에서는
   보수적 쪽을 택했습니다. 그 선택의 근거 또한 train 에서 측정합니다 —
   확장 시 **한계정밀도**가 손익분기(F1/2)보다 낮다는 것을 `derive_postproc.py` 가 수치로 보입니다.

## 실행

```bash
python src/step1_features.py      # work/feats.pkl      (~2분)
python src/step2_tsdens.py        # work/Xts.npy        (~3분)
cd tuning
python derive_hyperparams.py      # ~20분
python derive_postproc.py         # ~25분
python derive_features.py         # ~20분
python verify_constants.py        # 즉시
```

전체 약 70분입니다. 본 예측 생성(`run_all.py`, 약 5.5분)과는 독립이며, 검증 목적으로만 실행합니다.
