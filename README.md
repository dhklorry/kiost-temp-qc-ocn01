## 3. 접근 방법

### 3.1 문제의 성격

제공된 학습 데이터는 776,706행이지만 **독립적인 사건은 이상 세그먼트 263개**뿐입니다(spike 101, noise 50, flatline 48, offset 28, drift 24, 중첩 13). 행 수는 같은 사건을 수백 번 복사한 것에 가깝습니다.

따라서 이 문제의 핵심은 피처를 늘리는 것이 아니라 **263개 표본에 과적합하지 않는 것**입니다. 실제로 피처 404개 · 부스팅 500회 · 리프 63개 구성은 확률이 극단적으로 이분화(90분위 ≈ 0.0000, 99분위 ≈ 1.0000)되어 미지 연도에서 확률 순위가 무너졌고, **피처 75개 · 리프 15 · 반복 200**으로 축소했을 때 성능이 뚜렷하게 개선됐습니다.

### 3.2 피처 설계 (75개)

모든 지표는 **정점·층 단위로 표준화**합니다. 층별 국소 변동 폭이 10배 이상 차이 나므로(예: I-ORS layer 7 ≈ 0.10℃ vs layer 4 ≈ 1.15℃) 전 구간 공통 임계값은 성립하지 않습니다.

- **기준선/스케일**: 일 중앙값 → 15일 롤링 중앙값을 기준선, 롤링 MAD를 스케일로 사용. `z = (temp − 기준선)/스케일`. 계절과 위치에 따라 임계값이 자동으로 조정됩니다.
- **층간 잔차 `zres_lay`**: 같은 기지·같은 시각 다른 층들의 `z` 중앙값 대비 편차. offset·drift의 주 신호입니다.
- **기지간 잔차 `zres_all`**: 같은 연도 타 기지 대비 편차. G-ORS는 단층이라 층간 잔차를 만들 수 없어 이 채널이 대신합니다.
- **정합필터** (offset·drift 탐지의 핵심): 박스카(구간 안 평균 − 주변 링 평균) 6개 스케일(1h~48h 반폭), 램프(국소 선형 기울기) 4개 스케일, 계단 검출기와 그 과거/미래 방향 최대값 전파(12h/48h/96h). 계단 정보를 구간 내부까지 전파해야 경계뿐 아니라 구간 전체를 잡을 수 있습니다.
- **수온-염분 거칠기 비율 `roughratio`**: `log(수온 거칠기 / 염분 거칠기)`. 염분에는 이상이 주입되지 않으므로 noise 구간에서만 이 비율이 치솟습니다.
- **T-S 회귀 잔차 `tsres`**: 시계열별 ±7.5일 창에서 이상값을 2회 다운웨이팅하는 강건 회귀 `temp ~ psal`. 수괴의 국소 T-S 관계에서 벗어난 정도로, 층간 비교와 독립적인 채널입니다.
- **밀도 `sigma-t`**: EOS-80으로 계산한 밀도와 인접 층 밀도차. 주입된 수온 이상이 물리적으로 불가능한 밀도 역전을 만드는 경우를 포착합니다.
- **flatline**: 연속 동일값 런 길이 + 4개 창의 zero-diff 비율.
- **spike**: 정규화 1차 차분, 곡률, `min(|앞차분|, |뒤차분|)`.
- **성층 지표**: 위층·아래층과의 온도차와 그 계절 편차. 수온약층이 발달해 층간 상관이 소실되는 시기를 모델이 인지하고 층간 잔차의 신뢰도를 낮출 수 있게 합니다.

### 3.3 모델

`sklearn.ensemble.HistGradientBoostingClassifier`
```
max_leaf_nodes=20, min_samples_leaf=400, max_iter=250,
learning_rate=0.05, max_features=0.5, l2_regularization=1.0
시드 300~314의 15개 모델 확률 평균
```
결측은 라이브러리가 기본 지원하는 방식으로 처리합니다(G-ORS 2026 `depth` 전체 결측, I-ORS 2026 layer 3 미운영 등).

### 3.4 후처리

1. **히스테리시스**: 확률 0.60 이상인 씨앗을 포함하는 연결 구간을 확률 0.06까지 확장. 긴 구간의 앞뒤 꼬리를 회수합니다.
2. **갭 메움**: 2시간(12스텝) 이하로 끊긴 구간을 연결.
3. **최소 지속시간**: 3시간(18스텝) 미만 구간 제거. 단, 주입 명세상 spike는 10분이므로 **단일 포인트이면서 확률 0.5 이상**인 경우는 유지합니다.
   문제지가 명시한 최소 지속시간은 flatline 2시간(12스텝)이지만, 홀드아웃 검증에서는 18스텝이 더 나았습니다.
   12~17스텝짜리 짧은 구간을 포기하는 대신 오탐을 크게 줄이는 거래이며, 검증에서 오탐 431→306 / 미탐 1,946→1,992 로 순이득이었습니다.

임계값은 공격적으로 완화할수록 검증 점수는 오르지만 실제 테스트에서는 떨어집니다(확률 하위 구간의 한계정밀도가 검증 0.515 vs 실측 0.25~0.32). 위 값은 실측 기준 작동점입니다.

### 3.5 검증 프로토콜

미지 연도(2026)에 대한 일반화를 측정하기 위해 다음을 사용했습니다.

1. **기지-연도 단위 홀드아웃**: S-ORS 2024 / S-ORS 2025 / I-ORS 2025 / G-ORS 2025를 통째로 제외하고 학습·평가. 같은 기지·연도의 다른 층이 학습에 들어가면 층간 잔차의 기준계열을 공유해 누출이 생기므로 `sid` 단위 CV는 낙관적입니다.
2. **1~6월 구간 제한**: 테스트가 2026년 1~6월만 담고 있으므로 평가 구간을 맞춥니다. 학습 계열의 1~6월 양성 비율은 계열별로 0.42%~9.97%까지 요동치므로, "계열당 4% 일정"이라는 가정은 연 단위에서만 성립합니다.

`anomaly_type` 열은 선택 항목이며 순위에 반영되지 않으므로, 탐지된 구간의 통계량(런 길이, 거칠기 대비, 램프 대 계단 비)에 기반한 간단한 규칙으로 채웁니다.

## 4. 상수의 출처 — 재현 검증 대비

`src/step3_train_predict.py` 에는 모델 하이퍼파라미터와 후처리 임계값이 상수로 들어 있습니다.
**이 값들은 전부 `data/train.csv` 로부터 적합했으며, 리더보드 점수를 역산해 정한 값이 아닙니다.**

이를 코드로 증명할 수 있도록 `tuning/` 디렉터리에 도출 스크립트를 동봉했습니다.

| 상수 | 근거 | 도출 스크립트 |
|---|---|---|
| 모델 하이퍼파라미터 `CFG` | 정규화 격자 × 기지-연도 홀드아웃 CV | `tuning/derive_hyperparams.py` |
| 후처리 `HI` `LO` `GAP` | 홀드아웃 OOF 격자 탐색 | `tuning/derive_postproc.py` |
| 후처리 `MINLEN`=18 | 홀드아웃 OOF 격자 탐색 (문제지 최소값 12포인트보다 크게 잡아, 짧은 구간을 버리고 정밀도를 얻는 거래) | `tuning/derive_postproc.py` |
| 피처 75개 `CUR` | 후보 풀·무작위 부분집합과 홀드아웃 CV 비교 (아래 주 참고) | `tuning/derive_features.py` |
| `anomaly_type` 판정 규칙의 6 / 0.35 / 0.9 | 탐지된 구간에 유형 이름을 붙이는 간단한 규칙. **순위에 반영되지 않는 선택 열** 에만 쓰이며 `label` 에는 영향이 없음 | — |
| 창 크기, ε, EOS-80 계수 | 시간 스케일 설계 / 물리 상수 | — |

> **피처 목록의 출처에 대한 주**
> 75개 목록은 단일한 체계적 절차의 산출물이 아니라, 후보군을 넓혔다 줄이는 반복 실험 끝에 정착한 조합입니다.
> 따라서 `derive_features.py` 는 "이 목록이 어떻게 만들어졌는지"를 재현하지 않고,
> **"이 목록이 train 기반 검증에서 대안들보다 낫다"** 를 보입니다 — 후보 풀 전체(400개)보다도,
> 무작위 75개 세 벌보다도 좋습니다. 선택과 검증에 쓰인 정보는 `train.csv` 뿐입니다.

```bash
cd tuning && python verify_constants.py    # 위 도출 결과와 패키지 상수의 일치 확인
```

자세한 내용과 판정 기준은 `tuning/README.md` 를 보십시오.
도출 스크립트는 `is_test==0` 행만 읽으며, 본 예측 생성 경로(`run_all.py`)와 독립입니다.
